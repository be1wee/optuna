# Использование ИИ

При подготовке работы я использовал ИИ как помощника:

- для выбора библиотеки и исследуемого механизма;
- для поиска нужных классов и методов в исходном коде Optuna;
- для объяснения непонятных участков кода;
- для создания презентации

С помощью ИИ проверялись запуск демо и оформление слайдов.
